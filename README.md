# haus by hang. 沆設計 官方網站

沆室內裝修有限公司（haus by hang. / 沆設計）的官方網站。

- 正式網域：hausbyhang.com
- 技術：Next.js（App Router、TypeScript）、Tailwind CSS、Supabase、Vercel
- 規格文件：專案內「沆設計官網 規格與資料表 v1」

## 常用指令

```bash
npm run dev    # 本機開發，開啟 http://localhost:3000
npm run build  # 正式版建置，提交前必須通過
npm run lint   # 程式碼檢查
```

## 環境變數

複製 `.env.example` 為 `.env.local` 並填入真實值。`.env.local` 不會提交到 Git。
